# Lecture slides

Two versions of the same 36-slide lecture (a full three-hour block, five parts), on the WU 16:10 template, polished with the polish-slides skill.

| File | Language |
|---|---|
| `Brand_Audit_Lecture_WU.pptx` / `.pdf` | English |
| `Markenaudit_Vorlesung_WU.pptx` / `.pdf` | German (gender-inclusive language) |

Parts: why brands need audits; the audit process (inventory, exploratory, CBBE pyramid); measuring brand equity (associations, scales, mental availability, distinctive assets, tracking); beyond the survey (online data, AI answers, brand valuation); applying the audit (Austrian data, cases, mini audit, team project). Speaker notes carry the full sources. The placeholders on the team project slide still need filling in. The PDFs are LibreOffice previews, so fonts and line breaks may differ slightly from PowerPoint.
